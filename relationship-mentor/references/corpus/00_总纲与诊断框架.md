## 二、五阶段流程（主诊断轴）

任何一段关系从零到稳定，都要穿过五个关口。**先判断用户卡在第几关**，
不要在他卡在"约不出来"时去教他"怎么聊天"。

```
① 认识与初识  →  ② 聊天建立连接  →  ③ 邀约见面  →  ④ 关系升级  →  ⑤ 长期经营
```

### ① 认识与初识
- **目标**：建立起"有印象、愿意继续"的第一印象，拿到后续联系的自然理由。
- **关键动作**：状态先于话术（眼神、声音、松弛感）；给出具体而非泛泛的赞美；真实表达来意，不伪装成"顺便"。
- **常见卡点**：接近焦虑、开口困难、社交软件匹配率低、展示面失真。
- **自检**：如果对方愿意继续对话、主动回问，这一关就过了。卡住通常是**量不够或状态不对**，不是话术问题。

### ② 聊天建立连接
- **目标**：从信息交换走向情绪交换，让对方觉得"跟你聊天有意思"。
- **关键动作**：故事 > 问答；情绪线 + 逻辑线并行（双线话题）；少查户口、多分享自己的真实经历与观察；
  先给后取——先提供情绪价值，再提要求。
- **常见卡点**：连环提问、只聊安全话题、秒回且字数碾压、不敢表达真实想法。
- **自检**：对方是否开始主动开启话题、是否出现玩笑与调侃。没有 = 还停在信息层。

### ③ 邀约见面
- **目标**：把线上/初识的关系落到线下，见面是关系的真正起点。
- **关键动作**：模糊邀约先行（"下次一起去…"），再转具体邀约（时间+地点+低压力）；
  给对方容易答应的选项；被拒不追问原因，留余地。
- **常见卡点**：不敢提、提得太正式、被拒后纠缠、见面安排太贵太刻意。
- **自检**：约不出来几乎只有一个原因——**线上还没建立足够的安全感与兴趣**。回去补第 ② 关。

### ④ 关系升级
- **目标**：从"聊得来"变成"互相在意"。
- **关键动作**：有度地表达好感（不躲闪也不压迫）；循序渐进地自我暴露；抓关键节点（深夜长谈、
  共同经历、单独旅行）；用"我们"句式共建记忆。
- **常见卡点**：一直暧昧不敢表态、突然表白把压力一次给满、只做舒适感不做张力。
- **自检**：升级是前面所有步骤的自然结果，不是靠一次表白完成的。

### ⑤ 长期经营
- **目标**：让关系在平淡里持续有生命力。
- **关键动作**：对等投入；持续自我成长（不是"追到就通关"）；冲突时先稳自己再谈事；
  在彼此擅长的领域互相带领；定期创造新体验。
- **常见卡点**：付出感失衡、"你应该懂我"、用沉默惩罚对方、停止自我成长。
- **自检**：长期关系的敌人不是第三者，是**停止成长和停止表达**。

## 三、五模块诊断（用于卡在单条对话里）

当问题更微观（"刚才那句怎么接""这个局面怎么破"）时，用这套：

| 模块 | 要解决的问题 | 判断问题 |
|---|---|---|
| **打开** | 有没有建立起对话入口 | 对方有没有在接话、回问？ |
| **前提** | 有没有恰当地表达意图与好感 | 对方知不知道你对她有兴趣？强度合不合适？ |
| **评估** | 双方有没有在判断彼此是否契合 | 你们在聊品质与价值观，还是只在客套？ |
| **叙事** | 有没有让对方了解真实的你 | 她能说出三件关于你的具体事吗？ |
| **收尾** | 有没有导向一个具体的下一步 | 这次互动结束时有明确的下一步吗？ |

**诊断口诀**：先问"有没有下一步"，再问"她了不了解你"，再问"她知不知道你的意思"。
大多数"聊死"死在**没有收尾**——聊得很好，但没有自然地把互动引向下一件事。

## 四、能力阶梯（用户该练什么）

不要给新手上高级课。按这个顺序补：

1. **心态层**：配得感、接近焦虑的接纳、不向外求认可、被拒后的客观归因。
2. **表达层**：声音与语速、开放式提问、讲故事、幽默感、接住情绪。
3. **边界层**：守住自己的节奏、不讨好、敢表达底线、言行一致。
4. **推进层**：读信号、有度表达好感、渐进升级、收尾导向下一步。
5. **经营层**：对等投入、冲突处理、持续吸引、共同成长。

**判断原则**：用户反复出问题的那一层，才是该练的那一层。
一个边界层有问题的人，练再多话术也没用。

## 五、五种常见用户画像

接到案例先归类，再给路径：

| 类型 | 表现 | 根因 | 路径 |
|---|---|---|---|
| **缺经验型** | 没怎么接触过异性，容易神化对方 | 样本太少 | 先扩量、降低单次权重，不谈技巧 |
| **缺进攻性型** | 聊得不错但永远不推进 | 怕破坏现状、怕被拒 | 练最小步升级：每次互动留一个具体下一步 |
| **缺安全感型（索取型）** | 需要不断确认对方在不在乎 | 自我价值外挂 | 向内建立自我认同，停止用对方的行为给自己打分 |
| **缺情绪表达型** | 理性、讲道理、不会接情绪 | 情绪词汇贫乏 | 练"接情绪不接辩解"：先复述感受，再谈事实 |
| **恐惧亲密型** | 关系一近就退缩或搞砸 | 害怕被看见/被抛弃 | 这不是技巧问题，建议放缓节奏并考虑专业支持 |

## 六、高频反模式（看到就先指出来）

- **讨好**：秒回、无底线迁就、抢着买单、把对方的需求永远排在自己前面。
- **索取确认**：反复问"你到底喜不喜欢我"、用冷战测试对方。
- **查户口式聊天**：连续的封闭式提问，像面试。
- **过早倾倒脆弱**：刚认识就讲创伤与原生家庭，把对方当治疗师。
- **隐藏意图**：明明想发展恋爱关系，却装成"只是朋友"，最后怨对方不给机会。
- **纠缠**：被拒绝后追问原因、反复解释、换号联系。
- **停止成长**：确定关系后放弃外形、社交、事业与爱好。
- **情绪极端时做决定**：深夜提分手、吵架时说狠话。内置护栏：**情绪极端时不做重大关系决定。**

## 七、快速决策树

```
用户提问
 ├─ 涉及安全/暴力/自伤/诈骗 ────────────► 转介专业帮助，不按情感问题处理
 ├─ 想追/想推进
 │   ├─ 还没认识/不敢开口 ──────────────► 心态层 + ① 认识与初识
 │   ├─ 认识了但聊不起来 ───────────────► ② 聊天 + 模块"打开/叙事"
 │   ├─ 聊得来但约不出 ─────────────────► 回补 ② ，再查 ③ 邀约
 │   ├─ 见面了但没进展 ─────────────────► ④ 升级 + 模块"前提/收尾"
 │   └─ 一直暧昧不敢表态 ───────────────► ④ 升级：渐进表达 + 抓节点
 ├─ 关系出问题
 │   ├─ 冷淡/降温 ──────────────────────► 先判投入失衡还是外部选择，再谈策略
 │   ├─ 频繁吵架 ──────────────────────► 沟通三要素（信息/观点/情绪）+ 冲突降温
 │   ├─ 已分手想挽回 ──────────────────► 停止纠缠 → 复盘根因 → 只提供情绪价值
 │   └─ 长期平淡 ──────────────────────► ⑤ 经营：新体验 + 持续成长 + 表达需求
 └─ 自我建设（没具体对象）
     └─ 外形 / 事业 / 社交圈 / 内在 ────► 能力阶梯，缺哪层补哪层
```

## 八、三条底层原则

1. **吸引力来自真实状态，不来自表演。** 语料里所有有效的东西，本质都是"一个活得不错的人
   自然流露出来的状态"；所有无效的东西，本质都是"表演一个活得不错的人"。
2. **关系是对等的现实，不是征服或臣服。** 守住自己 ≠ 压制对方。
3. **技巧永远服务于真实连接。** 一旦某个技巧需要你伪装、隐瞒或施压，它就已经越界了。
